# 参考资料

本目录只放与本项目直接相关的文档。

## 厂商资料已移出仓库

以下模块/开发板的厂商资料（数据手册、示例工程、烧录教程）已从项目根目录移出到
仓库之外的同级目录 `../../01模块资料/`（即 `01STM32单片机/01模块资料/`），
不纳入 git 跟踪：

| 资料 | 大小 | 说明 |
|---|---|---|
| `STM32F407(黄色开发板)/` | 1.5 GB | 板级原理图与厂商示例 |
| `05-课程代码/` | 286 MB | 配套课程示例工程 |
| `0.96寸OLED屏8脚白带字库ssd1306/` | 24 MB | SSD1306 资料 |
| `esp32cam固件烧录教程/` | 17 MB | ESP32-CAM 烧录教程 |
| `GY521mpu-6050资料-/` | 8 MB | MPU6050 资料 |

移出的原因：这些内容体量大（合计约 1.8 GB）且与固件编译无关，留在项目根目录会
淹没真正的源码。`User/Template.uvprojx` 中对以上目录的引用为 0 处，移出后编译
链不受影响。

对应的原始压缩包（`.rar` / `.zip`，约 1.3 GB）是上述目录的冗余副本，不保留。

- `../reference_ui/` —— OLED 界面布局效果图（AI 生成的设计草图，非实机照片）
